# Sella

<img width="375" height="353" alt="image" src="https://github.com/user-attachments/assets/8cc92eb6-f1d7-4a94-ab5f-1f448592d653" />

Sella is a utility for finding first order saddle points

An example script
```python
#!/usr/bin/env python3

from ase.build import fcc111, add_adsorbate
from ase.calculators.emt import EMT

from sella import Sella, Constraints

# Set up your system as an ASE atoms object
slab = fcc111('Cu', (5, 5, 6), vacuum=7.5)
add_adsorbate(slab, 'Cu', 2.0, 'bridge')

# Optionally, create and populate a Constraints object.
cons = Constraints(slab)
for atom in slab:
    if atom.position[2] < slab.cell[2, 2] / 2.:
        cons.fix_translation(atom.index)

# Set up your calculator
slab.calc = EMT()

# Set up a Sella Dynamics object
dyn = Sella(
    slab,
    constraints=cons,
    trajectory='test_emt.traj',
)

dyn.run(1e-3, 1000)
```

## CPU acceleration and concurrent optimizers

The Genesis fork accelerates regular molecular bond, angle and dihedral values,
exact gradients and directional Hessian products, Hessian guesses, Jacobian
assembly, and CPU QR/eigh with cached Numba nopython kernels. Periodic, singular
and fragment-rotation cases retain the reference JAX paths. Set
`SELLA_DISABLE_NUMBA=1` to select the reference implementation. `sella.warmup()`
eagerly compiles both float64 and float32 CPU solver signatures, so a caller can
overlap compilation with fetching inputs.

`configure_compute` must run before optimizer workers start; settings apply to
all optimizers in the process. Generic defaults retain float64 Hessian solves
and uncapped concurrency. For a batch of independent optimizers sharing a GPU
energy/force model:

```python
from sella import configure_compute, warmup

configure_compute(
    max_cpu_threads=1,
    use_gpu=False,
    hessian_eigh_dtype="float32",
    hessian_eigh_max_concurrent=6,
    hessian_eigh_min_dim=200,
)
warmup()
```

Only approximate Hessian eigensolves use the selected precision. Optimizer
state, returned eigenpairs, QR and coordinate derivatives stay float64. Failed
or nonfinite float32 eigenpairs retry in float64. Float32 can change optimization
trajectories and the local minimum reached; choose it for workloads where that
tradeoff is acceptable. Disabling Sella's GPU algebra leaves the calculator's
GPU device unchanged. Matrices smaller than the configured minimum bypass the
shared concurrency limit.

When GPU algebra is enabled, the CPU/GPU defaults are 500 rows for eigh and 700
for QR. `SELLA_GPU_EIGH_MIN_DIM` and `SELLA_GPU_QR_MIN_DIM` override these;
`SELLA_GPU_MIN_DIM` remains the common override. OOM falls back to CPU.
The exact derivative sources are generated by the scripts in `tools/`, using
SymPy as a development dependency; SymPy is not required at runtime.
